# Deployment assets

This directory contains the integration and conformance assets currently available for Runku
storage and runtime profiles.

| Directory | Scope |
|---|---|
| [`docker/`](docker) | Dedicated development and conformance dependencies |
| [`kubernetes/`](kubernetes) | Distributed Full Node Agent and scale-test topology |
| [`standalone/`](standalone) | Dedicated host and Firecracker host requirements |
| [`firecracker/`](firecracker) | Firecracker benchmark image and guest initialization assets |

These assets are not yet a certified production distribution. See the
[self-hosting overview](../docs/self-hosting/overview.md) for the precise support boundary.
