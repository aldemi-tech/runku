# Governance

Runku is maintained by Aldemi. Maintainers review changes for correctness, compatibility, security,
and operational supportability.

Public protocols and persisted formats change through reviewed pull requests with migration or
compatibility evidence. Repository access, release signing, and security response remain restricted
to designated maintainers. The governance model may evolve as the contributor community grows.

## Decisions, releases, and transparency

Maintainers own merge/support/release decisions and protect signing/security material. Changes to
domain invariants, public/persisted contracts, trust boundaries, supported profiles, or compatibility
windows require an explicit public decision and named maintainer approval.

A release requires reproducible artifacts, checksums/SBOM/provenance/signatures, changelog,
compatibility/upgrade notes, security review, documentation, and evidence for every claimed profile.
Reviewers disclose material conflicts and recuse when appropriate. Embargoed security details are
the only routine exception to public technical reasoning.
